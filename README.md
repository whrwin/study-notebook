# Study Notebook

Study Notebook 是一个面向学生的 AI 学习笔记 Web MVP。本版本优先完成 PDF 导入、连续阅读、透明文字笔记和本地批注原型，为后续 Word、PPT、GPT 辅助学习、同步和更完整的 PDF 导出打基础。

## 安装与启动

```bash
npm install
npm run dev
```

开发服务器启动后，按终端提示打开本地地址即可使用。

## 已实现功能

- React + TypeScript + Vite 项目结构
- 上传 PDF 并连续渲染所有页面
- 左侧笔记栏，可点击文字笔记跳转到对应位置
- 左侧页面栏，可快速跳转到 PDF 页面
- 添加透明文字笔记，结束编辑后不显示明显文本框
- 文字笔记支持拖动、编辑文字、删除
- 文字笔记支持字体大小、颜色、加粗设置
- 荧光笔和画笔批注
- 批注颜色、粗细、透明度设置
- 橡皮擦删除文字笔记或笔迹
- 使用 localStorage 自动保存 PDF 与批注，刷新后恢复
- 导出当前项目批注 JSON
- 通过浏览器打印功能导出 / 另存为 PDF

## 使用说明

1. 点击顶部的“上传 PDF”选择学习资料。
2. 选择“text”工具后在页面上点击，即可直接输入透明文字笔记。
3. 鼠标移到文字笔记上，或点击选中后，可以拖动、删除或修改样式。
4. 选择“highlight”或“pen”后，在 PDF 页面上拖动即可批注。
5. 左侧“笔记”列表可以跳转到对应文字笔记。
6. 点击“导出 PDF”会打开浏览器打印窗口，在打印窗口中选择“存储为 PDF”即可。
7. 点击“导出 JSON”可以下载当前批注数据。
